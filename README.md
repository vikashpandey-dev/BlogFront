# Sunday Journal — Static React Blog

A responsive blog starter built with React, Vite, and React Router. No backend or database is required.


## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize posts
Edit the `posts` array in `src/main.jsx`. Each post includes `id`, `category`, `title`, `excerpt`, `author`, `date`, `read`, `image`, and `body`.


## Notes
- Blog content is stored in the frontend source.
- Newsletter form is demo-only; it shows a confirmation alert and does not save emails.
- Images use Unsplash URLs; replace with your own assets if desired.
